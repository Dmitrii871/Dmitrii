# Шаблон вертикальных рилсов на Remotion

Композиция `Reel` — 1080×1920, 30 fps. Все параметры ролика приходят
через props, поэтому новый ролик делается правкой одного файла:
`src/Root.tsx` (блок `defaultProps`) или отдельного json с пропсами.

Шаблон не только оформляет, но и монтирует: сам вырезает паузы, режет
запись на планы, ставит переходы, меняет крупность и подкладывает музыку,
которая прижимается под голос. Длительность считается из результата
монтажа — хардкода таймингов нет.

## Быстрый старт

```bash
npm install
npm run dev
```

Откроется Remotion Studio с готовым примером из `public/example/`.

Рендер:

```bash
npx remotion render Reel out/reel.mp4 --props=examples/basic-reel/props.json
```

Подробности — куда класть видео, где брать `.srt`, какие флаги у рендера —
в [examples/README.md](examples/README.md).

## Props

| Параметр             | Тип             | Что делает                                                        |
| -------------------- | --------------- | ----------------------------------------------------------------- |
| `videoSrc`           | `string`        | Путь к видео внутри `public/` или полный URL                      |
| `title`              | `string`        | Заголовок первых 2 секунд, `\n` — перенос строки                  |
| `captionsSrc`        | `string`        | Путь к `.srt` внутри `public/`, тайминги — по исходнику           |
| `accentColor`        | `string` (цвет) | Активное слово субтитров и фон финальной плашки                   |
| `ctaText`            | `string?`       | Текст финальной плашки; без него слой не рисуется                 |
| `autoCutSilence`     | `boolean`       | Вырезать паузы, где человек молчит                                |
| `maxDurationSeconds` | `number`        | Потолок длины готового ролика                                     |
| `shotTransition`     | `"none"｜"fade"｜"slide"` | Склейка планов: встык, затемнение или сдвиг              |
| `dynamicZoom`        | `boolean`       | Наезд внутри плана и разная крупность на соседних планах          |
| `musicSrc`           | `string?`       | Фоновая музыка внутри `public/`; без неё слой не рисуется         |
| `musicVolume`        | `number`        | Громкость музыки в паузах, 0..1                                   |

Схема описана через zod (`reelSchema` в `src/Reel.tsx`), так что в Studio
props правятся в боковой панели, а `accentColor` — пипеткой.

## Как работает монтаж

Всё решается один раз в `calculateMetadata` (`src/Reel.tsx`), дальше слои
только рисуют готовый таймлайн.

1. **Разбор звука** — `src/edit/analyze-audio.ts`. Дорожка декодируется
   через mediabunny, считается громкость окнами по 40 мс. Значения
   нормируются по самому громкому месту ролика, поэтому порог не зависит
   от того, тихо или громко записал телефон.
2. **Нарезка на планы** — `src/edit/build-shots.ts`. Участки громче порога
   становятся планами, паузы короче 400 мс не режутся (иначе речь рубится
   на середине фразы), к краям добавляется запас 130 мс, обрывки короче
   350 мс выбрасываются. В конце всё обрезается по `maxDurationSeconds`.
3. **Сборка таймлайна** — `src/edit/timeline.ts`. Считает, где каждый план
   стоит в готовом ролике с учётом того, что переходы съедают время.
   Это единственный источник правды для длительности, субтитров и музыки.
4. **Отрисовка** — `src/layers/EditedVideoLayer.tsx`. `TransitionSeries`,
   каждый план со своей крупностью и медленным наездом.

Если дорожки нет или её не удалось разобрать, ролик берётся целиком —
рендер не падает.

## Слои

| Файл                             | Что делает                                                       |
| -------------------------------- | ---------------------------------------------------------------- |
| `src/layers/EditedVideoLayer.tsx`| Планы, переходы, зум и смена крупности                            |
| `src/layers/TitleLayer.tsx`      | Заголовок 0–2 с: подложка, размытие, тень, акцентная линия        |
| `src/layers/CaptionsLayer.tsx`   | Субтитры по 2–3 слова, активное слово — `accentColor`             |
| `src/layers/CtaLayer.tsx`        | Плашка на последние 2 секунды, привязана к `durationInFrames`     |
| `src/layers/MusicLayer.tsx`      | Музыка с автоматическим приглушением под голос                    |

Вспомогательное:

- `src/captions/srt-to-pages.ts` — разбор srt, раздача таймингов по словам,
  нарезка на страницы по 2–3 слова;
- `src/edit/remap-captions.ts` — перенос субтитров на смонтированный
  таймлайн: слова из вырезанных кусков выбрасываются, остальные сдвигаются;
- `src/lib/get-video-duration.ts` — длительность исходника;
- `src/lib/font.ts` — шрифт;
- `src/lib/resolve-src.ts` — путь в `public/` или внешний URL.

## Шрифт и кириллица

Montserrat с Google Fonts, вариативный файл лежит в
`public/fonts/Montserrat-Variable.ttf` (лицензия OFL) — латиница и кириллица
в одном файле, все начертания от 100 до 900.

Файл, а не запрос к `fonts.gstatic.com`, специально: так кириллица не зависит
от сети во время рендера. Типовая поломка выглядит так — шрифт подключили
одной строкой без списка subsets, приехала только латиница, а русский текст
молча отрисовался системным шрифтом (в headless-браузере при рендере — часто
вообще квадратами).

Если нужен вариант с сетевой загрузкой — в `src/lib/font.ts` лежит
закомментированная замена на `@remotion/google-fonts` с обязательным
`subsets: ["cyrillic", "cyrillic-ext", "latin", "latin-ext"]`.

## Что где подкрутить

| Хочу                                   | Где                                                      |
| -------------------------------------- | -------------------------------------------------------- |
| Режет слишком агрессивно / мало режет   | `silenceThreshold`, `minSilenceMs` в `src/Reel.tsx`      |
| Обрезает начало слов                    | `paddingMs` там же                                       |
| Другие крупности планов                 | `SHOT_VARIANTS` в `src/layers/EditedVideoLayer.tsx`      |
| Длиннее или короче переход              | `TRANSITION_FRAMES` в `src/Reel.tsx`                     |
| Субтитры перекрывает интерфейс          | `paddingBottom: 430` в `src/layers/CaptionsLayer.tsx`    |
| Заголовок перекрывает интерфейс         | `paddingTop: 300` в `src/layers/TitleLayer.tsx`          |
| Музыка слишком прижимается под голосом  | диапазон в `interpolate` в `src/layers/MusicLayer.tsx`   |
