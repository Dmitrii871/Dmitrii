# Пример: вертикальный рилс 1080×1920

В этой папке лежит готовый пример — `basic-reel/props.json`. Это полный набор
параметров одного ролика. Всё, что нужно для нового рилса, меняется в нём
(или в `defaultProps` в `src/Root.tsx`), компоненты трогать не надо.

## Что уже работает из коробки

В `public/example/` лежат демо-файлы, чтобы шаблон запускался сразу:

- `video.webm` — сгенерированный тестовый клип, 12 секунд, 1280×720
  (горизонтальный — специально, чтобы было видно, как работает кадрирование
  `cover` под вертикаль; в кадр вписан таймкод, по нему удобно сверять
  синхронность субтитров). На дорожке четыре «реплики» с паузами между ними,
  на них видно работу автонарезки: 12 секунд превращаются в 6,6. Формат webm
  выбран только для демо — так клип играет в любой сборке Chromium;
  для своих роликов бери обычный mp4;
- `captions.srt` — четыре реплики на русском;
- `music.mp3` — короткая петля для проверки фоновой музыки.

Запусти `npm run dev` и открой композицию `Reel` — увидишь результат.

## Куда класть своё видео

1. Положи файл в папку `public/`. Удобно держать каждый ролик в своей
   подпапке: `public/my-reel/video.mp4`.
2. Пропиши путь **относительно `public/`, без ведущего слэша**:

   ```json
   "videoSrc": "my-reel/video.mp4"
   ```

Формат — обычный `.mp4` (H.264 + AAC). Подойдёт и вертикальный, и
горизонтальный исходник: кадр обрезается по центру через
`objectFit: "cover"`, пропорции не искажаются.

Длительность композиции считается из результата монтажа, так что таймкоды
нигде не прописываются руками. Плашка CTA сама встаёт на последние
2 секунды любого ролика.

Можно указать и полный `https://`-адрес вместо пути в `public/` — тогда
файл не придётся хранить в репозитории.

## Где взять .srt с субтитрами

Файл кладётся туда же, в `public/`, и указывается в `captionsSrc`.

Варианты, откуда его взять:

- **Уже есть у ролика.** Instagram, TikTok, YouTube и CapCut умеют
  выгружать автосубтитры в `.srt`.
- **Whisper локально** — самый точный вариант для русского:

  ```bash
  pip install -U openai-whisper
  whisper public/my-reel/video.mp4 --model medium --language ru \
    --output_format srt --output_dir public/my-reel
  ```

  Получится `public/my-reel/video.srt` — переименуй в `captions.srt`
  или укажи как есть.
- **Онлайн-сервисы**: Whisper через веб-интерфейсы, Descript, Vizard,
  Submagic — все отдают `.srt` на экспорте.
- **Руками.** Формат простой, шаблон переваривает и файлы без нумерации
  блоков, и CRLF, и BOM:

  ```srt
  1
  00:00:02,200 --> 00:00:04,600
  Первые три секунды решают всё
  ```

Слой субтитров сам разбивает реплики на страницы по 2–3 слова и раздаёт
словам тайминг внутри реплики пропорционально длине — отдельная разметка
по словам не нужна.

## Монтаж

Шаблон сам режет запись, если `autoCutSilence` включён:

- слушает дорожку и выбрасывает паузы, где ты молчишь;
- каждый оставшийся кусок становится отдельным планом;
- соседние планы получают разную крупность — общий, средний, крупный, —
  а внутри плана кадр медленно едет. Из одного вертикального видео
  с телефона это читается как смена ракурса;
- на склейках ставится переход, заданный в `shotTransition`;
- готовый ролик обрезается по `maxDurationSeconds`.

Субтитры размечаются **по исходнику**, до нарезки — Whisper или любой
сервис отдаёт srt именно так. Пересчёт на смонтированный таймлайн шаблон
делает сам: слова из вырезанных пауз выбрасываются, остальные сдвигаются.
Переделывать srt после монтажа не нужно.

Если результат режет слишком жадно или, наоборот, оставляет паузы —
крутится в `src/Reel.tsx`: `silenceThreshold` (порог тишины),
`minSilenceMs` (какая пауза считается паузой), `paddingMs` (запас
по краям реплики).

Выключить монтаж и оставить только оформление: `autoCutSilence: false`,
`dynamicZoom: false`, `shotTransition: "none"`.

## Музыка

Положи трек в `public/`, укажи путь в `musicSrc` — он подмешается фоном
и будет автоматически прижиматься, когда ты говоришь. `musicVolume`
задаёт громкость в паузах, разумные значения 0.3–0.6.

Трек короче ролика зациклится сам. Убрать музыку — удалить `musicSrc`
из пропсов.

## Параметры

| Параметр             | Обязательный | Что делает                                                   |
| -------------------- | ------------ | ------------------------------------------------------------ |
| `videoSrc`           | да           | Путь к видео в `public/` (или полный URL)                    |
| `title`              | да           | Заголовок первых 2 секунд, `\n` — перенос строки             |
| `captionsSrc`        | да           | Путь к `.srt` в `public/`, тайминги по исходнику              |
| `accentColor`        | да           | Цвет активного слова и фона плашки CTA                       |
| `ctaText`            | нет          | Текст финальной плашки                                       |
| `autoCutSilence`     | да           | Вырезать паузы                                               |
| `maxDurationSeconds` | да           | Потолок длины ролика                                         |
| `shotTransition`     | да           | `none`, `fade` или `slide`                                   |
| `dynamicZoom`        | да           | Наезд и смена крупности планов                               |
| `musicSrc`           | нет          | Фоновая музыка                                               |
| `musicVolume`        | да           | Громкость музыки в паузах, 0..1                              |

## Как рендерить

Пример из этой папки:

```bash
npx remotion render Reel out/basic-reel.mp4 --props=examples/basic-reel/props.json
```

Свой ролик — тот же путь, свой json:

```bash
npx remotion render Reel out/my-reel.mp4 --props=examples/my-reel/props.json
```

Если правишь `defaultProps` прямо в `src/Root.tsx`, `--props` не нужен:

```bash
npm run render out/my-reel.mp4
```

Полезные флаги:

- `--concurrency=4` — сколько ядер занять;
- `--crf=18` — качество (меньше число — выше качество и вес);
- `--scale=0.5` — быстрый черновик в половинном разрешении;
- `npx remotion still Reel out/frame.png --frame=45 --props=...` — вытащить
  один кадр, чтобы проверить вёрстку без полного рендера.

## Превью

```bash
npm run dev
```

Откроется Remotion Studio. Композиция `Reel`, справа — панель props:
цвет можно потыкать пипеткой, текст поменять прямо там, и Studio запишет
изменения обратно в `defaultProps` в `src/Root.tsx`.
