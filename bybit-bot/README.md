# Bybit Trading Bot

Торговый бот для Bybit (API v5, бессрочные USDT-контракты). Открытый код, без подписок
и платных сервисов. Два режима: вход по совпадению индикаторов и маркет-мейкинг на спреде.

## Сначала прочитайте это

Бот — это исполнитель дисциплины, а не источник дохода. Он снимает эмоции, соблюдает
стоп-лоссы и не спит по ночам. Но зарабатывать он будет ровно настолько, насколько
прибыльна заложенная в него стратегия.

Проверить это можно и нужно **до** того, как рисковать деньгами:

```bash
python tools/backtest.py --demo --bars 3000
```

Прогон на случайном блуждании даёт минус примерно на величину комиссий. Так и должно быть:
на данных без структуры прибыльной стратегии не существует. Если бы демо показало плюс —
значит, в бэктесте ошибка. Это калибровка честности движка.

Три вещи, которые определяют результат больше, чем код бота:

1. **Комиссии.** Тейкер 0.055%, мейкер 0.02%. Круг тейкером = 0.11%. Сделка с тейк-профитом
   меньше 0.11% убыточна по построению — бот откажется запускаться с такой настройкой.
2. **Размер счёта.** Минимальный лот ETHUSDT — 0.01 ETH ≈ 25 USDT нотионала. На депозите
   в 40 USDT вы не можете ни дробить позицию, ни пересиживать просадку. Одна серия из
   четырёх стоп-лоссов по 0.8% — это уже заметная часть депозита.
3. **Плечо.** 3x означает, что движение рынка на 1% меняет ваш капитал на 3%. Плечо
   увеличивает и доход, и скорость потери депозита.

Самоматчинг (торговля бота с самим собой ради объёма) в этом проекте не реализован
и реализован не будет: это нарушение правил Bybit, ведущее к аннулированию наград и блокировке.

## Установка

```bash
git clone <repo> && cd bybit-bot
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env                  # вписать ключи
cp config.example.yaml config.yaml    # настроить параметры
```

**Ключи API.** Создайте с правами только `Trade` (Orders + Positions). Право на вывод
средств не включать никогда. Привяжите ключ к своему IP. Для тестов заведите отдельные
ключи на [testnet.bybit.com](https://testnet.bybit.com) — там торговля идёт фантиками.

## Порядок запуска

Проходите ступени по очереди, не перепрыгивая.

```bash
# 1. Бэктест: есть ли у стратегии прибыль на истории вообще
python tools/backtest.py --symbol ETHUSDT --interval 30 --bars 3000

# 2. Подбор параметров: тот же тест с другими TP/SL и порогом совпадения
python tools/backtest.py --symbol ETHUSDT --interval 30 --bars 3000 --tp 2.0 --sl 1.0 --confluence 3

# 3. Сухой прогон: testnet: true, dry_run: true — ордера только в лог
python -m bot.main --config config.yaml

# 4. Testnet: dry_run: false, testnet: true — реальные ордера, ненастоящие деньги
python -m bot.main --config config.yaml

# 5. Mainnet: testnet: false + флаг --live + подтверждение с клавиатуры
python -m bot.main --config config.yaml --live
```

Не переходите к шагу 5, пока шаг 4 не проработал хотя бы неделю без вмешательства.

## Стратегии

### `signal` — вход по совпадению индикаторов

Те же индикаторы, что у вас на графике: RSI 14, MACD 12/26/9, Bollinger %B 20/2.
Каждый голосует «лонг», «шорт» или воздерживается. Вход только при согласии
`min_confluence` индикаторов из трёх. Выход — по take-profit и stop-loss, которые
выставляются **на самой бирже**: позиция защищена, даже если бот упадёт или пропадёт связь.

Сигналы считаются один раз на закрытии свечи, а не на каждом тике — это убирает
дёрганье внутри бара и лишние комиссии.

### `maker` — заработок на спреде

Бот держит лимитные заявки с обеих сторон от середины рынка и зарабатывает разницу
между ценой покупки и продажи. Котировки смещаются при накоплении инвентаря: набрали
длинную позицию — котировки съезжают вниз, чтобы охотнее продать.

Стратегия отказывается стартовать, если `spread_bps` не покрывает комиссию мейкера.
Главный риск — движение рынка в одну сторону: вас наберут по одной стороне, и вы
останетесь с позицией против тренда. Поэтому `max_inventory_usdt` обязателен.

## Риск-контур

Проверяется на каждом цикле, до отправки любого ордера:

| Параметр | Что делает |
|---|---|
| `max_position_usdt` | Потолок нотионала позиции |
| `max_daily_loss_usdt` | Просадка от старта сессии — бот закрывает позицию и останавливается |
| `min_free_margin_ratio` | Порог свободной маржи, защита от ликвидации |
| `max_orders_per_hour` | Защита от разгона комиссий при сбое логики |
| `kill_switch_file` | `touch STOP` — аккуратная остановка без убийства процесса |

Разделение намеренное: стратегия думает о прибыли, риск-менеджер — о том, чтобы
депозит пережил серию её неудачных решений.

## Структура

```
bot/
  indicators.py        RSI, MACD, Bollinger %B — чистый Python, формулы как в TradingView
  exchange.py          обёртка Bybit v5: округление до tick/step, ретраи, dry_run
  models.py            типы, которыми обмениваются слои
  risk.py              лимиты и аварийная остановка
  strategies/
    signal.py          вход по совпадению индикаторов
    maker.py           маркет-мейкинг на спреде
  main.py              цикл, CLI, защита от случайного запуска на mainnet
tools/backtest.py      бэктест с учётом комиссий, просадки и профит-фактора
tests/                 16 тестов индикаторов и логики
```

## Тесты

```bash
python -m pytest tests -q
```

## Что дальше

- Прогоните бэктест на нескольких символах и периодах. Стратегия, прибыльная только
  на одном отрезке, — это подгонка, а не преимущество.
- Ведите журнал: `bot.log` пишется автоматически.
- Увеличивайте размер позиции только после того, как накопится 100+ сделок
  с положительным профит-фактором.

## Отказ от ответственности

Торговля с плечом сопряжена с риском потери всего депозита. Код предоставляется
как есть, без гарантий прибыли. Результаты на истории не предсказывают будущее.
Решения о сделках — ваши.
